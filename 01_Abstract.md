# Abstract

This project presents the design and implementation of an Internet of Things (IoT)-based wireless LED control system using the ESP8266 NodeMCU microcontroller and the Blynk mobile application platform.

The system enables users to remotely control multiple LEDs through a smartphone using WiFi communication. The implementation provides real-time LED switching, status synchronization, and responsive mobile interaction through cloud-based communication.

The project demonstrates a low-cost and scalable smart lighting solution suitable for:
- Smart home automation
- Educational IoT demonstrations
- Embedded systems experimentation
- Prototype development

Experimental testing validated:
- 100% command responsiveness
- Reliable wireless communication
- End-to-end latency below 500 ms
- Stable multi-device synchronization

The overall system provides a practical introduction to IoT architecture, cloud communication, and embedded system integration.
